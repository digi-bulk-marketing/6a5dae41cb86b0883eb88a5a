# CTA Button Lite

CTA Button Lite by Inkanidea Marketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a5dae41cb86b0883eb88a5a/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **CTA Button Lite** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a5dae41cb86b0883eb88a5a/releases/latest) and reinstall.
